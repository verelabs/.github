A finished piece hides everything that went into it: the false starts, the ninety sessions, the draft deleted at 2am. Then someone in the comments asks if any of it is real.

Vere Labs builds tools that let the work answer for itself, a record of how something was actually made, anchored so it can't be backdated, showing only as much as the maker chooses to reveal.

**[velender](https://github.com/verelabs/velender)** turns a Blender project's history into a receipt: anchored snapshots, a timelapse, a page anyone can verify.

**[enclave](https://github.com/verelabs/enclave)** is a private writing workspace that proves when your words were actually written, and lets you show, separately and only if you choose, where a model helped.

Effort is evidence. Proof shouldn't cost privacy. Verification shouldn't need us.
