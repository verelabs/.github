Finished work hides its own making: the false starts, the ninety sessions, the draft deleted at 2am, all invisible in the final file. Then someone asks if it's even real.

We build tools that let work vouch for itself. Records that can't be backdated, that reveal only as much as the maker chooses, and that anyone can check without having to trust us about it.

**[velender](https://github.com/verelabs/velender)** turns a Blender project's history into a receipt: anchored snapshots, a timelapse, a page anyone can verify.

**[enclave](https://github.com/verelabs/enclave)** is a private markdown workspace where AI provenance is its own layer, shareable separately from the writing itself.

Effort is evidence. Proof shouldn't cost privacy. Verification shouldn't need us.
